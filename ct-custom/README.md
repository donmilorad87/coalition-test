# CT Custom theme

Coalition skill-test theme: a pixel-perfect PSD conversion with a 3-level menu, a Theme Settings page
(logo, contact details, social links, SMTP), Customizer design tokens, Font Library fonts, and Reach Us /
Social Links blocks built with the Interactivity API.

The full documentation (Docker setup, `.env`, theme structure, admin guide, development commands) is in
[`../README.md`](../README.md).

Quick start for development:

```bash
npm install && npm run build
composer install   # PHPUnit + PHPCS (WordPress, WordPress VIP Go)
```
